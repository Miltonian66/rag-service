# Onboarding a new robot

To add a robot to a fleet, power it on, connect it to the network over Ethernet, and scan the QR code on its base with the Northwind mobile app. The robot downloads the latest stable firmware automatically; the first update takes about 15 minutes.

After the update, run the calibration routine from the console. Calibration moves each joint through its full range and takes roughly 8 minutes. A robot cannot receive tasks until calibration has finished successfully.
